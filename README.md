# Top 250 Movies Data Analysis

## Overview
This project involves web scraping and data analysis of the Top 250 movies listed on IMDb. Utilizing Python and Selenium, I extracted crucial information about each movie, including titles, release years, ratings, and durations. The data was then analyzed and visualized using Power BI for insightful reporting.

## Features
- **Web Scraping**: Automated extraction of movie data from IMDb's Top 250 chart.
- **Data Processing**: Organized the scraped data into a structured CSV format.
- **Data Analysis**: Conducted exploratory data analysis to identify trends in movie ratings, release years, and genres.
- **Reporting**: Created interactive reports and visualizations using Power BI to present the analysis results.

## Technologies Used
- Python
- Selenium
- Pandas (for data manipulation)
- CSV (for data storage)
- Power BI (for reporting and visualization)
